# EVOXU website

Responsive static company website based on EVOXU_Complete_Website_Content.docx. Open dist/index.html, or serve dist with any static HTTP server. No build or dependencies required.

Includes accessible opportunity tabs, mobile navigation, expandable career information, interest selection, and a validated enquiry file download. Enquiries are not transmitted: connect a contact endpoint and replace the download handler before accepting direct submissions. No company email, telephone, address, or results were invented. Photography uses externally hosted Unsplash images; fonts use Google Fonts.
